# スマホの向こう側

子どもたちのグループトーク体験。小学生・中学生・高校生のスマホに届く3日間を体験し、子どもたちの言葉の意味と、話してもらえる声かけを学ぶページです。

- 家庭版：https://japrican.github.io/mukougawa/
- 学校版：https://japrican.github.io/mukougawa/#school

## 中身

- **保護者版（約15分）**：学年を選び、わが子のスマホに届く3日間のグループトークを体験して、家での声かけを選ぶ
- **子ども版（約10分）**：「される側」の3日間を体験し、送る側の自分をふり返る
  - 小学生：仲間はずれのグループ編／あだ名とかくされたもの編
  - 中学生：いじり返し編／陰口グループ編／静かな仲間はずれ編
  - 高校生：裏アカ編／なりすまし・写真拡散編
  - どのお話も3通りの会話パターンがあり、選んだ返事によって展開が変わります
- 学校版（URLの最後に `#school`）では、講座などの案内を表示せず、授業での問いの例を表示します
- 入力内容や選んだ答えは、どこにも送信・保存されません

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | ページ本体（HTML・CSS・JavaScriptをすべて含む1ファイル） |
| `share.png` | SNSでシェアしたときに表示される画像（1200×630） |
| `.nojekyll` | GitHub Pagesでそのまま公開するための空ファイル |

## 公開のしかた（GitHub Pages）

1. リポジトリ `mukougawa` を Public で作り、上の3つのファイルをアップロード
2. **Settings → Pages** で、ブランチ `main`、フォルダ `/ (root)` を選んで保存
3. 数分後に https://japrican.github.io/mukougawa/ で公開されます
